# Kamour Voyages v2

نسخة Static جاهزة للرفع على Vercel.

- لا توجد API ولا مفاتيح خارجية.
- لا توجد أسعار للفنادق.
- الاختيار المتدرج: الدولة ← المدينة ← الفندق.
- نموذج حجز منظم.
- عند الإرسال تُفتح WhatsApp برسالة منظمة إلى Kamour Voyages.
- طلبات الطيران والتواصل أيضًا عبر WhatsApp.
- Français / عربي.
- Responsive للهاتف والكمبيوتر.
